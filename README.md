# Woodmark Youth

Мобильное приложение для молодёжной группы (iPhone и Android).

Описание продукта и все решения: [docs/SPEC.md](docs/SPEC.md).

## Как посмотреть прототип

```bash
npm install
npx expo start
```

Дальше: клавиша `w` — открыть в браузере, `i` — в симуляторе iPhone, либо отсканировать QR-код приложением Expo Go на телефоне.

Есть файл `.env.local` (образец — `.env.example`) — приложение работает с настоящей базой. Нет файла — запускается демо-режим на выдуманных данных.

## База данных

```bash
npm run test:db     # тесты правил доступа и анонимности (локально, без облака)
supabase db push    # применить изменения структуры к проекту Youth
```
